# KSJ 대화형 모드 범위 밖 질문 수정

## 문제 원인

- `score_threshold=0.0`으로 검색 임계값이 꺼진 상태였습니다.
- `"배고파요"`처럼 범위 밖인 질문도 FAISS가 가장 가까운 법령 청크를 반환했습니다.
- 기존 인용 검증은 질문과 근거의 관련성을 검증한 것이 아니라, 모델이 적은
  C-ID가 검색 문서 목록에 있는지만 확인했습니다.
- 그 결과 관련 없는 법령 청크를 사용한 답변도 검증된 출처처럼 표시되었습니다.

## 수정 내용

- 하이브리드 검색 점수가 `0.50` 미만이면 LLM을 호출하기 전에 즉시 거부합니다.
- 특정 평가 질문이나 정답 조문을 코드에 넣지 않았습니다.
- 하이브리드 검색에서 FAISS의 raw score API를 사용해 음수 relevance 경고가
  출력되지 않게 했습니다.
- `jhgan/ko-sbert-nli + FAISS + hybrid` 검증 분포에 맞춰 검색 임계값을
  `0.50`으로 설정했습니다. 현재 답변 가능 문항의 최저점은 `0.55`,
  범위 밖 dense-only 질문은 약 `0.45`였습니다.
- 공용 `rag_chain.py`는 수정하지 않았습니다.

## 교체할 파일

프로젝트의 아래 파일만 덮어쓰면 됩니다.

```text
src/ksj_rag_chain_generic.py
```

`main_copy_ksj.py`는 이전 속도 수정본과 같지만, 함께 제공한 압축 파일을 통째로
덮어써도 됩니다.

## 확인 방법

```bat
python src\main_copy_ksj.py --interactive --no-use_ragas
```

다음처럼 확인합니다.

```text
질문> 배고파요
산업안전보건법령에서 해당 내용을 찾을 수 없습니다.

질문> 크레인 설치·조립 작업 때 어떤 조치를 해야 하나요?
관련 법령 근거를 이용한 답변 출력
```

첫 번째 질문은 벡터 검색 점수만 확인하고 LLM 생성을 실행하지 않으므로 빠르게
끝나야 합니다.
